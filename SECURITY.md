# Security Policy

## Supported Versions

Only the latest release and the default branch receive security fixes, so report vulnerabilities against one of them. A fix lands on the default branch and ships with the next release.

## Reporting a Vulnerability

Report vulnerabilities privately with the **Report a vulnerability** button on the repository's security tab, following [GitHub's guide](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability), and keep them out of public issues and pull requests. Include the affected version or commit, reproduction steps or a proof of concept, and the expected impact.

The maintainer replies in the advisory, coordinates disclosure with you, and publishes the advisory once a fix is released.
