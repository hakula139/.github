# Security Policy

## Supported Versions

Only the latest release and the default branch receive security fixes, so report vulnerabilities against one of them. A fix lands on the default branch and ships with the next release.

## Reporting a Vulnerability

Report vulnerabilities privately with the **Report a vulnerability** button on the repository's security tab, as [GitHub's guide](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) describes, and keep them out of public issues and pull requests. Include the affected version or commit, the steps to reproduce or a proof of concept, and the impact you expect.

The maintainer replies in the advisory, coordinates disclosure with you, and publishes the advisory once a fix is released.
