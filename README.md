# .github

Default community health files for [hakula139](https://github.com/hakula139)'s repositories. GitHub falls back to each file here in any repository that lacks its own copy:

- [Pull request template](.github/pull_request_template.md)
- [Bug report and feature request forms](.github/ISSUE_TEMPLATE)
- [Security policy](SECURITY.md)

A repository overrides a file by adding its own. Any file in its own `.github/ISSUE_TEMPLATE/`, even a lone `config.yml`, replaces all the default forms. The forms apply the `bug` and `enhancement` labels, which must exist in the repository.
